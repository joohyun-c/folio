# folio — 나로부터 시작하는 책 발견

**folio**는 내 취향을 입력하고 책을 발견해 나만의 책장에 모으는 웹페이지입니다. 국내 책은 카카오 책 검색 연결을 먼저 시도하고, 해외 책은 Google Books와 Open Library를 함께 찾습니다. 외부 검색이 모두 실패하면 편집 예시 책을 보여줍니다. 잡지 화면에서는 일본 잡지의 실제 부록 사진을 중심으로 둘러봅니다.

## 실행과 눈으로 확인하기

이 폴더에서 웹 서버를 시작한 뒤 브라우저로 `http://localhost:8765`에 접속합니다. `dist/index.html`을 파일로 직접 열면 `curiosities.json`을 불러오지 못할 수 있습니다. 지금 실행 중인 8765 화면의 저장 책장은 그대로 사용할 수 있습니다.

```sh
python -m http.server 8765 --directory dist
```

첫 화면에서 **관심 주제·읽는 이유·분량**을 고르고 **책 찾아보기**를 누르면 외부 검색 결과와 편집 책 중 조건에 맞는 책을 최대 세 권 보여줍니다. 추천 카드에서 실제로 맞은 조건, 책의 세부 분류, 확인되지 않은 정보를 따로 볼 수 있고 **관심 없음**을 누르면 다른 후보가 올라옵니다. 더 세밀하게 고르고 싶을 때만 **취향 더 자세히 설정하기**를 엽니다. 책 상세에서 **내 취향 보드에 담기**를 할 수 있고, **표지 밖의 재미**에서 잡지 부록 사진도 같은 보드에 담을 수 있습니다. **내 책장**에서는 직접 만든 보드와 읽는 단계별 책을 먼저 볼 수 있고, 통계와 자동 주제 모음은 펼쳐서 봅니다.

화면은 표지와 한 줄 소개가 먼저 눈에 들어오는 서점 가판대와 인쇄 잡지에서 착안했습니다. 종이색과 흰색을 바탕으로 제목 크기와 장식의 대비를 줄여 책 표지가 중심이 되도록 했습니다. 영어 문구는 화면의 시각적 제목으로만 쓰고, 선택과 동작 설명은 한국어로 유지했습니다.

## 국내 도서 검색 연결 상태

한국어 책 검색에는 [카카오 Daum 책 검색](https://developers.kakao.com/docs/ko/daum-search/dev-guide)을 연결했습니다. 제목·저자·소개·ISBN·표지를 folio 책 카드로 바꾸고, 검색 다음 페이지·출처 표시·중복 제거·기존 추천 흐름에 반영합니다. 연결 코드는 `server.cjs`에 있고 비밀 인증값인 REST API 키는 웹페이지 파일에 넣지 않습니다. **현재 이 컴퓨터에는 카카오 REST API 키가 없어 실제 국내 책 응답은 아직 확인하지 못했습니다.** 키가 없으면 화면에 ‘국내 책 검색 미연결’이라고 표시하고 기존 해외 검색으로 이어집니다. 검색 결과를 흉내 낸 자료로 책 카드·다음 페이지·출처·키 비노출을 검사했습니다.

실제 연결 시에는 카카오 개발자 앱에서 발급받은 REST API 키를 `.env`의 `FOLIO_KAKAO_REST_KEY`에 넣고, `.env.example`을 참고해 별도 검색 서버를 실행합니다. 현재 8765 화면의 브라우저 저장 책장을 유지하려면 `.env`에 `PORT=8767`을 두고 `node --env-file=.env server.cjs`로 실행합니다. `.env`는 Git에서 제외됩니다. 공개 배포 때는 화면과 검색 서버를 같은 사이트로 배치해야 합니다. [공식 이용량 안내](https://developers.kakao.com/docs/ko/getting-started/quota)의 책 검색 한도와 실제 응답은 운영 전에 확인해야 합니다.

**무료 이용 확인(2026-10-06):** 카카오 공식 안내에서 Daum 책 검색은 하루 30,000건, Daum 검색 전체는 하루 50,000건의 무료 제공량이 있고, 전체 API 월간 무료 제공량은 3,000,000건입니다. 책 검색의 별도 초과 이용 요금은 요금표에 표시되지 않습니다. [공식 REST API 응답 안내](https://developers.kakao.com/docs/ko/rest-api/reference)에 따르면 Daum 검색이 쿼터(호출 한도)를 초과하면 429 오류로 요청이 제한됩니다. folio는 그때 다른 검색으로 이어가고 ‘국내 책 검색 요청 한도 도달’을 표시합니다. 쿼터와 정책은 바뀔 수 있으며, 이 프로젝트에서는 유료 API 설정이나 결제 연결을 하지 않습니다.

**네이버 책 검색은 후보에서 제외했습니다.** [네이버의 공식 종료 공지](https://developers.naver.com/notice/article/32530)에 따르면 이 API는 2026년 7월 31일 종료됐고 NAVER API HUB에도 대체 API가 없습니다. 기존 검색 API 설명서는 남아 있지만 현재 이용 가능하다는 뜻이 아닙니다. 사용자가 카카오 앱 생성을 보류했으므로, 새 키가 필요한 서비스는 신청하지 않습니다. 한국어 책의 표지·소개를 넓게 찾으면서 앱·키 등록을 전혀 하지 않는 안정적인 국내 API는 이번 공식 자료 조사에서 확인하지 못했습니다.

Goodreads는 책장·추천·리뷰의 **기능 비교 대상**이며 도서 데이터 공급원으로 사용하지 않습니다.

## Google 계정 연결 상태

**실제 Google 로그인은 아직 작동하지 않습니다.** 사용자가 선택한 대로 사주 서비스와 분리된 folio 전용 Supabase 프로젝트를 사용할 계획입니다. 로그인·계정별 책장·브라우저 책장 가져오기 코드는 `dist/auth.js`에 준비했지만, 새 프로젝트 생성과 연결 설정은 끝나지 않았습니다. 따라서 현재는 작동하지 않는 로그인 버튼을 숨기고 이 브라우저의 책장을 사용합니다. 다른 기기와 동기화된다고 표시하지 않습니다.

연결에 필요한 일은 다음 순서입니다.

1. folio 전용 Supabase 프로젝트를 만듭니다.
2. Google 로그인 제공자와 이 웹페이지의 복귀 주소를 설정합니다.
3. `supabase/migrations/202610060001_folio_libraries.sql`을 적용해 계정별 책장과 본인만 읽고 쓰는 제한 규칙을 만듭니다.
4. `dist/auth-config.js`에 프로젝트 URL과 공개 연결값인 publishable key를 넣습니다. Google Client Secret이나 service role 키는 브라우저 파일에 넣지 않습니다.
5. 실제 로그인·로그아웃, 브라우저 책장 가져오기, 다른 브라우저에서 복원, 계정 A/B 분리를 검증합니다.

참고: [Supabase Google 로그인](https://supabase.com/docs/guides/auth/social-login/auth-google), [복귀 주소 설정](https://supabase.com/docs/guides/auth/redirect-urls), [계정별 접근 제한](https://supabase.com/docs/guides/database/postgres/row-level-security). 로그인 전 취향과 메모는 브라우저 저장소에 남습니다. 책을 찾을 때 주제·커리어 세부 관심사·분위기나 입력한 책/작가 이름은 카카오 책 검색(키 연결 시), Google Books 또는 Open Library에 검색어로 전송됩니다.

## 일본 잡지 부록 데이터 갱신

`dist/curiosities.json`은 사람이 원문을 확인해 넣은 **편집 목록**입니다. 2026-10-06에 [宝島社의 リンネル](https://tkj.jp/liniere/202611/), [otona MUSE](https://tkj.jp/otonamuse/202611/), [sweet](https://tkj.jp/sweet/202610/), [MonoMax](https://tkj.jp/max/202610/) 공식 호수와 부록을 확인했고, 알라딘의 [MonoMax](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=391846745)·[リンネル](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=391010778) 판매 페이지도 연결했습니다. 여섯 사진은 부록 사진이며 잡지 표지와 구별해 표시합니다.

항목에는 부록 종류(`category`), 발행 호, 구성, 상품/발행사 주소, 사진 주소·출처, 확인 날짜가 있습니다. 새 호를 확인한 뒤 이 파일에 추가하면 화면에 반영됩니다. **실시간 재고·가격·자동 수집 기능은 없습니다.** 오래된 7월호는 발행 호가 보이도록 남겼으며 현재 구매 가능하다고 주장하지 않습니다. 사용자가 제시한 [알라딘 부록 종류별 모음전](https://www.aladin.co.kr/events/wevent.aspx?EventId=309111)과 [YES24 일본 무크지·부록 기획전](https://event.yes24.com/bookMagazine?Eventno=110205&CategoryNumber=002)을 화면에 연결했습니다. 공개 배포 전에는 외부 이미지 사용 조건과 주소 안정성을 확인해야 합니다.

## 파일과 보존본

`dist/index.html`은 화면, `dist/styles.css`는 디자인, `dist/app.js`는 책·추천·책장 동작, `dist/curiosities.json`은 부록 목록입니다. `server.cjs`는 카카오 책 검색을 대신 요청하는 서버이고 `.env.example`은 그 설정 예시입니다. `dist/auth.js`와 `dist/auth-config.js`는 계정 연결 코드와 공개 설정입니다. `supabase/migrations/`에는 계정별 책장 데이터베이스 규칙이 있습니다. 이번 변경 전 주요 파일은 `versions/folio-before-korean-books-2026-10-06-v01/`에 보존했습니다. 세부 작업 기록은 상위 폴더의 `작업일지.md`에 있습니다.
