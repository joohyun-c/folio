# folio — 기분으로 찾는 책

책을 읽고 싶지만 무엇을 고를지 막막할 때, 현재 기분에서 시작해 책을 탐색하는 웹페이지입니다. 표지를 둘러보는 화면에서 검색하거나 기분을 고르고, 마음에 드는 책을 내 책장에 저장할 수 있습니다.

## 첫 버전에서 할 수 있는 일

- 책 제목·저자 검색
- 기분별 책 탐색과 간단한 맞춤 추천
- 저장한 책·좋아하는 작가·선택한 기분을 조합한 개인 추천과 추천 이유
- 책 상세 정보 확인 및 내 책장 저장
- 작가를 선택해 다음 작품으로 이어 읽기, 좋아하는 작가 저장
- 영화와 원작 소설의 연결 탐색
- 실제 잡지 부록 4종을 유형별로 고르고 각 상품 페이지에서 구성 확인
- 실제 표지가 있는 큐레이션 책 20권과 출처가 확인된 책 속 문장 2개 보기
- 책마다 나만의 한 줄을 기기에 저장
- 모바일과 데스크톱에서 사용

## 데이터와 저장 방식

이 첫 버전은 제목·저자 검색에 API 키 없이 접근 가능한 Open Library 공개 검색 API를 사용합니다. 기분별 추천은 한국어 책으로 구성한 예시 큐레이션이며, 실제 API 검색 결과와 화면에서 구분합니다. 검색에 실패해도 기능을 확인할 수 있도록 예시 책을 표시합니다. 저장한 책은 현재 브라우저의 로컬 저장소에만 남으며, 다른 기기와 동기화되지 않습니다.

개인 추천은 저장한 책의 기분·작가, 저장한 좋아하는 작가, 직접 선택한 지금의 기분을 점수로 조합합니다. 점수가 높은 예시 책을 최대 3권 보여주고 각 책의 추천 이유를 표시합니다. 이미 저장한 책은 추천에서 제외합니다. 선택한 기분은 같은 브라우저에만 남고 화면에서 지울 수 있습니다. 로그인이나 외부 AI 호출 없이도 선택에 따라 결과가 달라지는 첫 단계이며, 책 목록이 작아 모든 독서 취향을 설명하지는 못합니다.

Google Books와 예스24 API는 후속 단계에서 검색 품질을 비교한 뒤 하나를 선택할 계획입니다. 두 서비스 모두 키 발급이 필요하며, 예스24 키는 서버에서만 관리해야 합니다. 이 저장소에는 API 키와 개인 정보가 포함되지 않습니다. 영화 원작과 작가 이어읽기는 아래 공개 출처를 확인한 소규모 수동 큐레이션입니다. 큐레이션 책의 표지는 확인한 예스24 상품 판본의 이미지 URL을 표시하고, 표지가 로드되지 않으면 책 제목을 대체 표지로 보여줍니다. 잡지 부록은 확인한 개별 알라딘 상품으로 연결하며 가격·재고를 자체 표시하지 않습니다.

첫 화면의 『불편한 편의점』과 『구의 증명』 문장은 예스24 상품 페이지의 ‘책 속으로’에 있는 짧은 본문 구절입니다. 각 카드에 작품명, 쪽수, 원문 링크를 표시했습니다. 공개 배포 전 이미지와 인용문의 사용 조건을 다시 확인할 예정입니다. 영화 원작 카드의 질문은 이 프로젝트가 직접 작성했습니다.

## Pinterest에서 다음에 적용할 것

우선순위는 **책장 보드 분리(읽고 싶어요 / 읽는 중 / 읽었어요)**, 그다음은 **저장한 책을 출발점으로 한 관련 책 제안**입니다. Pinterest의 보드·More ideas 흐름은 저장 후 다시 발견하게 만드는 점이 유용합니다. 책장 분리는 현재 브라우저 저장 구조를 확장해야 하므로 이번 화면에서는 빠른 저장까지만 구현했습니다. 무한 스크롤은 출처가 섞인 도서를 계속 노출해 판단을 어렵게 할 수 있어 보류했습니다.

## 실행

`dist/index.html`을 웹 서버에서 열면 됩니다. 예: 프로젝트 폴더에서 `python3 -m http.server 8000 --directory dist`를 실행하고 `http://localhost:8000`에 접속합니다.

## 다른 노트북에서 이어서 작업하기

1. 이 GitHub 저장소의 **Code** 버튼에서 주소를 복사합니다.
2. 새 노트북에서 `git clone <복사한 주소>`를 실행합니다. Git은 저장소 파일을 노트북으로 가져오는 도구입니다.
3. 복제된 폴더에서 위의 `python3 -m http.server 8000 --directory dist` 명령을 실행합니다.

GitHub에는 사이트 코드와 설명서만 들어갑니다. 책장·개인 추천 설정·나만의 한 줄은 각 브라우저에만 저장되므로 다른 노트북으로 자동 이동하지 않습니다.

## 다음 검증

1. 한국어 책 제목 5개를 검색해 결과의 제목·표지·소개를 확인합니다.
2. 기분별 추천 결과가 선택한 기분과 맞는지 확인합니다.
3. 저장·삭제 후 새로고침해 책장 상태가 유지되는지 확인합니다.
4. Google Books와 예스24 중 첫 정식 데이터 공급원을 선정합니다.
