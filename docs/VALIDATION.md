## 아직 확인하지 못한 것

1. 서로 다른 취향의 독자가 후보와 추천 이유를 직접 평가했을 때 실제로 책 선택에 도움이 되는지.
2. 다른 기기에서 같은 계정의 기록을 불러오고, 서로 다른 두 계정의 데이터가 분리되는지.
3. 매월 새 잡지 호 확인 작업의 첫 실행과 그 변경 내용의 공개 사이트 반영.
4. 많은 책을 저장했을 때의 속도, 과거 저장 데이터 이전, 키보드 조작과 넓은 화면 사용성.

검증하지 않은 항목은 완료로 표시하지 않았습니다. 과거 평가 파일에는 당시 연결되지 않았던 자료원 상태가 남아 있으므로, 그 시점의 실험 기록으로 읽어야 합니다.
