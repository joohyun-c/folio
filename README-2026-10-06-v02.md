# folio — 나를 알아갈수록 이어지는 책 발견

folio는 사용자가 좋아한 책과 작가, 관심 주제, 읽는 목적을 바탕으로 다음 책을 발견하고 보드에 모아두는 웹페이지를 목표로 합니다. 책 표지를 둘러보다가 마음에 드는 책을 저장하고, 저장한 책에서 다시 관련 책으로 이어지는 경험을 지향합니다.

**현재 저장소의 코드는 이 목표의 첫 시제품입니다.** 지금은 기분별 탐색과 작은 예시 책 목록을 이용한 개인 추천이 구현되어 있습니다. 아래의 목표 기능과 현재 동작을 구분해 읽어 주세요.

## 직접 실행하기

프로젝트 폴더에서 다음 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000 --directory dist
```

Python 명령이 다른 이름으로 설치된 컴퓨터에서는 해당 컴퓨터의 Python 실행 명령을 사용합니다. 화면을 열면 제목·저자 검색, 책 저장, 작가 탐색, 잡지 부록 코너를 확인할 수 있습니다. 이 저장소는 정적 웹페이지이므로 별도의 설치 단계가 없습니다.

## 지금 사용할 수 있는 것

| 영역 | 현재 동작 | 확인할 점 |
| --- | --- | --- |
| 책 탐색 | 제목·저자를 Open Library에서 검색하고, 첫 화면에서는 수동으로 고른 한국어 책을 보여줍니다. | 검색 결과와 예시 책은 화면에서 구분합니다. 검색 품질은 책마다 다를 수 있습니다. |
| 개인 추천 | 저장한 책의 작가·기분, 좋아하는 작가, 선택한 기분을 조합해 수동 예시 책 20권 중 최대 3권을 추천합니다. | 검색해서 저장한 책은 현재 추천 후보 목록을 넓히지 않습니다. 읽는 목적·주제·분량도 아직 반영하지 않습니다. |
| 내 책장 | 책을 저장·삭제하고 책마다 나만의 한 줄을 남깁니다. | 내용은 현재 브라우저에만 저장됩니다. 다른 기기와 자동으로 이어지지 않습니다. |
| 이어서 발견하기 | 일부 작가의 다른 작품과 영화의 원작 소설을 연결합니다. | 정해 둔 소규모 목록이며, 저장한 책마다 관련 책이 자동으로 이어지지는 않습니다. |
| 잡지 부록 | 알라딘에서 확인한 상품 4종을 유형별로 보여주고 각 상품 페이지로 연결합니다. | 현재 카드 그림은 부록 실물 사진이 아닙니다. 다른 판매처도 아직 포함되지 않았습니다. |

현재의 표지 중심 화면과 빠른 저장은 Pinterest에서 참고한 첫 요소입니다. **보드별 정리와 저장한 책에서 출발하는 관련 추천은 아직 구현되지 않았습니다.**

## 다음에 만들 제품 경험

1. **나를 알려주기:** 관심 주제, 읽는 목적, 좋아했던 책·작가, 선호 분량을 짧게 선택합니다. 기분은 선택 가능한 보조 정보로 둡니다.
2. **책 발견하기:** 취향과 저장 행동을 반영한 책 카드를 보고, 카드마다 추천 이유를 확인합니다. 정보가 없으면 개인 추천이라고 표시하지 않고 탐색 목록을 보여줍니다.
3. **보드에 모으기:** `읽고 싶어요 / 읽는 중 / 다 읽었어요`에 책을 저장합니다. 저장한 책을 열면 비슷한 주제나 작가의 책으로 이어집니다.
4. **취향 고치기:** 관심 없는 추천은 제외하고, 선택을 바꾸면 다음 추천에 반영합니다. 이미 저장한 책의 반복 추천도 막습니다.

Google Books API는 이 흐름의 **책 정보 공급원 후보**입니다. 제목·저자·소개·분류·언어·표지를 받아 검색과 추천 후보를 만들 수 있습니다. 실제로 어떤 책을 추천할지와 이유는 folio가 사용자의 선택을 바탕으로 결정해야 합니다. Google Books 전환은 아직 구현하지 않았습니다. 2026-10-06에 이 작업 환경에서 시험한 키 없는 검색은 일일 사용 한도 오류(HTTP 429)로 실패했으므로, 한국어 검색·표지 품질과 안정적인 호출 방법은 별도로 검증해야 합니다.

## 잡지 부록 코너의 다음 기준

책 추천과 별도로, 알라딘 이외의 판매처에서 확인한 잡지·부록도 탐색할 수 있게 합니다. 각 카드는 **잡지 표지와 부록 실물 사진을 구분**하고, 판매처·상품 링크·확인 날짜를 표시합니다. 상품 사진을 확인하지 못했을 때는 대체 그림임을 분명히 표시합니다. 가격·재고·구성은 바뀔 수 있으므로 구매 판단은 연결된 상품 페이지에서 다시 확인하도록 합니다. Google Books의 잡지 표지만으로 부록 실물 사진을 대신하지 않습니다.

## 다음 완료 기준

| 단계 | 완료로 표시할 조건 |
| --- | --- |
| 사용자 기반 추천 | 서로 다른 취향 두 가지에서 추천이 달라지고, 표시된 추천 이유가 실제 입력·저장 기록과 일치합니다. |
| 책 데이터 | 한국어 책 검색·설명·표지를 여러 사례로 확인하고, 정보 누락·검색 실패 때도 상태를 정확히 안내합니다. |
| 보드와 관련 책 | 저장·이동·삭제가 새로고침 뒤에도 유지되고, 저장한 책에서 관련 책으로 이동할 수 있습니다. |
| 잡지 부록 | 둘 이상의 판매처에서 상품과 부록 구성을 확인하고, 실제 사진 또는 명시적인 대체 표시와 출처를 제공합니다. |

기능별 작은 수정과 실험 과정은 실습 폴더 최상위의 `작업일지.md`에 기록합니다. 이 표는 방문자가 체감할 수 있는 큰 기능이 실제로 확인됐을 때 갱신합니다.

## 데이터와 사용 범위

- 현재 검색은 [Open Library](https://openlibrary.org/developers/api)의 공개 정보를 사용합니다. 예시 책의 일부 표지는 확인한 [예스24](https://www.yes24.com/) 판본의 이미지 주소로 표시합니다.
- 사용자 책장·좋아하는 작가·선택한 기분·메모는 브라우저의 로컬 저장 공간에만 남습니다. 로그인, 기기 간 동기화, 외부 AI 추천은 현재 없습니다.
- 현재 잡지 부록은 [알라딘 행사](https://www.aladin.co.kr/events/wevent.aspx?EventId=309111)에서 확인한 소규모 목록입니다. 상품 사진 사용 조건과 책 표지·책 속 문장 인용 조건은 공개 배포 전에 확인해야 합니다.
- 공개 자료의 책 정보가 비어 있거나 잘못 연결될 수 있습니다. 추천 이유에는 실제로 확인한 사용자 선택과 도서 정보만 사용하도록 개선할 예정입니다.
