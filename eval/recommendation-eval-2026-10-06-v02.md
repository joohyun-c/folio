# folio 추천 근거 재평가 · 2026-10-06 · v02

## 평가 대상

[첫 평가](recommendation-eval-2026-10-06-v01.md)의 취향 입력 E01~E06을 새 추천 코드로 다시 실행했습니다. 사용자 `localhost:8765` 책장과 분리된 빈 시험 주소 `127.0.0.62:8765`~`127.0.0.67:8765`를 사용했습니다. 외부 검색 결과는 이번에도 카카오 미연결·Google Books 요청 제한 때문에 Open Library에서 왔습니다. 상위 3권에 Open Library 작품 소개를 비동기로 추가 조회한 뒤, 화면이 안정된 상태에서 읽는 목적 단서를 판정했습니다.

| 사례 | 선택한 읽는 이유 | 상위 3권 중 소개 표시 | 읽는 목적을 자료로 입증한 책 |
| --- | --- | ---: | ---: |
| E01 일과 커리어·데이터 | 실무에 적용 | 1 | 0 |
| E02 일과 커리어·금융 | 실무에 적용 | 1 | 0 |
| E03 일과 커리어·고객 | 실무에 적용 | 3 | 0 |
| E04 소설 | 몰입하는 이야기 | 3 | 0 |
| E05 과학 | 새로운 관점 | 1 | 0 |
| E06 여행 | 가볍게 읽기 | 2 | 0 |

**결과:** 상위 18권 가운데 11권에 책 소개가 표시됐습니다. 그러나 읽는 이유를 직접 입증한 책은 0/18권, 하나라도 입증한 입력 사례는 **0/6**입니다. E04의 소설 3권에는 소설 분류와 소개가 있다는 *참고 단서*가 표시됐지만, 몰입감을 입증한다고 주장하지 않았습니다. 소개를 불러오는 동안 상위 순서가 바뀔 수 있으므로 첫 순간의 목록만으로 판정하지 않았습니다.

## 이번 변경에서 실제로 나아진 점과 남은 한계

- 상위 후보의 Open Library 작품 설명을 더 찾아 책 상세뿐 아니라 추천 카드에도 표시합니다.
- 쪽수가 짧다는 사실을 ‘읽기 쉬움’으로, 소설 소개가 있다는 사실을 ‘몰입감 보장’으로 바꾸지 않습니다. 직접 단서가 없으면 ‘읽는 목적 일치 미확인’을 남깁니다. 이번 6개 시험에서 거짓 양성 표시는 발견하지 못했습니다.
- 평가 버튼은 사용자의 판단을 다음 순서에 반영하지만, 외부 자료의 빈칸을 채워 주지는 않습니다. 실제 읽는 목적 적합성 개선을 주장하려면 더 풍부한 책 소개 자료 또는 실제 독자 평가가 필요합니다.
- 이 평가는 개발자가 고른 6개 입력의 기능 평가입니다. 전체 도서 검색 정확도나 이용자 만족도 수치가 아닙니다.
